Entry for the [make.fun bounty "Deadpan Forecasts for Cities That Do Not Exist"](https://make.fun/bounty/u-coral-ibis-18-deadpan-forecasts-for-cities-that-do-151d4d8c): one absurd-but-believable deadpan weather line for an invented city.

`main.ts` writes a single line (142 characters) to `/output/entry.txt`:

> Tonight in Grumblewick: freezing rain, 2 centimetres, falling uphill, with gusts of 60 km/h returning every umbrella to the shop it came from.

Run it with `node main.ts`. The output is deterministic — two runs produce byte-identical files.
